# 大千式（標準）注音鍵盤對照表

這是台灣預設的標準注音鍵盤配置（大千式）。`scripts/decode_bopomofo.py` 的
`KEY_TO_BOPOMOFO` 就是這張表。**程式為準；這份文件供人工核對與腳本不可用時參考。**


## 聲調

| 聲調 | 符號 | 按鍵 |
|------|------|------|
| 一聲（陰平） | （無） | 空白鍵 |
| 二聲（陽平） | ˊ | `6` |
| 三聲（上聲） | ˇ | `3` |
| 四聲（去聲） | ˋ | `4` |
| 輕聲 | ˙ | `7` |

> 注意：26 個英文字母**全部**都對應到注音符號，所以「只看字元集」無法區分英文
> 與誤打注音。真正的判別靠「能不能完整切成合法國語音節」（見下）。

## 音節結構

一個合法國語音節 = **〔聲母〕**+**〔韻母（含介音）〕**+**〔聲調〕**，其中：

- **聲母（21）**：ㄅㄆㄇㄈ ㄉㄊㄋㄌ ㄍㄎㄏ ㄐㄑㄒ ㄓㄔㄕㄖ ㄗㄘㄙ
- **介音（3）**：ㄧ ㄨ ㄩ
- **韻尾**：ㄚㄛㄜㄝ ㄞㄟㄠㄡ ㄢㄣㄤㄥ ㄦ
- **聲調**：ˊ ˇ ˋ ˙（一聲無符號）

### 合法韻母清單（介音 + 韻尾的固定組合）

用固定清單而非「介音 + 韻尾隨意相配」，可避免 ㄩㄤ 這種不存在的組合被誤判。

```
單韻母      ㄚ ㄛ ㄜ ㄝ ㄞ ㄟ ㄠ ㄡ ㄢ ㄣ ㄤ ㄥ ㄦ
介音成韻    ㄧ ㄨ ㄩ
ㄧ 系       ㄧㄚ ㄧㄛ ㄧㄝ ㄧㄞ ㄧㄠ ㄧㄡ ㄧㄢ ㄧㄣ ㄧㄤ ㄧㄥ
ㄨ 系       ㄨㄚ ㄨㄛ ㄨㄞ ㄨㄟ ㄨㄢ ㄨㄣ ㄨㄤ ㄨㄥ
ㄩ 系       ㄩㄝ ㄩㄢ ㄩㄣ ㄩㄥ
```

**空韻聲母**（可只有聲母、無韻母）：ㄓ ㄔ ㄕ ㄖ ㄗ ㄘ ㄙ
（例：是 = ㄕˋ、日 = ㄖˋ、字 = ㄗˋ）

## 驗證用例（按鍵 → 注音 → 中文）

| 按鍵 | 注音 | 中文 |
|------|------|------|
| `su3` | ㄋㄧˇ | 你 |
| `cl3` | ㄏㄠˇ | 好 |
| `a8` | ㄇㄚ | 媽／嗎／麻（視聲調與上下文） |
| `su3cl3a8` | ㄋㄧˇㄏㄠˇㄇㄚ | 你好嗎 |
| `g4` | ㄕˋ | 是 |
| `2k7` | ㄉㄜ˙ | 的 |
| `dj94` | ㄎㄨㄞˋ | 快 |
| `vu,4` | ㄒㄧㄝˋ | 謝 |
| `ji3` | ㄨㄛˇ | 我 |

> ⚠️ 常見錯誤示範：坊間有些說明把 `g4dk4` 說成「今天」、`dj94` 說成「是的」，
> 這些**都是錯的**（`g4`=是、`dk4`=課；`dj94`=快）。這正是為什麼按鍵→注音
> 一定要交給腳本，不能靠記憶或心算。
